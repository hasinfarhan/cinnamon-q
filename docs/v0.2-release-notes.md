# Release v0.2: Application Upgrade

**Tag:** `v0.2-application`  
**Date:** November 2024  
**Status:** Production-Ready

## Overview

This release represents the transformation from a simple script to a production-grade, persistent application. The bot is now a resilient daemon that configures itself, remembers everything, and runs 24/7.

## What Changed

### Before (v0.1)
- Manual script (`run_bot.py`) that fired once
- Hardcoded constants throughout the codebase
- No persistence - forgot everything on restart
- Single execution - no scheduling

### After (v0.2)
- **Configuration-Driven**: YAML-based config with Pydantic validation
- **Persistent**: SQLite database remembers all trades
- **Scheduled**: Multi-timeframe orchestrator runs strategies on schedule
- **Self-Healing**: Reconciliation loop maintains state alignment
- **24/7 Operation**: Heartbeat loop runs continuously

## Usage

### Starting the Bot

```bash
python main.py
```

The bot will:
1. Load configuration from `config.yaml`
2. Initialize all services (Database, Trading Engine, Strategy Engines)
3. Run strategies immediately (first run)
4. Enter heartbeat loop, executing strategies on schedule
5. Run until interrupted (Ctrl+C)

### Configuration

All settings are in `config.yaml`:

```yaml
system:
  heartbeat_interval: 60  # seconds
  db_url: "sqlite:///arynosq.db"

strategies:
  - name: "momentum_bluechip"
    signal: "momentum"
    interval: "1d"  # Daily execution
    params:
      window: 30
      k: 3

execution:
  provider: "alpaca"
  paper: true
```

### Inspecting the Database

```bash
# View all trades
sqlite3 arynosq.db "SELECT * FROM trades;"

# View portfolio snapshots
sqlite3 arynosq.db "SELECT * FROM portfolio_snapshots;"
```

## Key Improvements

1. **Resilience**: Bot survives restarts and remembers state
2. **Transparency**: Complete audit trail in database
3. **Flexibility**: Config-driven behavior, no code changes needed
4. **Scalability**: Multi-strategy support with independent schedules
5. **Reliability**: Error handling and graceful shutdown

## Migration Notes

If upgrading from v0.1:
- Create `config.yaml` from the example
- Database will be created automatically on first run
- Old `run_bot.py` script is deprecated (use `main.py`)
